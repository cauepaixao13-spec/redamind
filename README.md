# 📖 Sobre

O **RedaMind** é uma plataforma web desenvolvida para tornar o estudo da redação do ENEM mais organizado, interativo e motivador.

O sistema utiliza gamificação, metas de estudo, flashcards e acompanhamento de desempenho para incentivar uma rotina consistente de aprendizado.

Este projeto foi desenvolvido utilizando **Angular 17**, seguindo boas práticas de desenvolvimento Front-End, arquitetura em componentes e interfaces responsivas.

# 🚀 Como executar

## Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/redamind.git
```

Entre na pasta

```bash
cd redamind
```

Instale as dependências

```bash
npm install
```

Execute o projeto

```bash
npm start
```

A aplicação estará disponível em:

```
http://localhost:4200
```
